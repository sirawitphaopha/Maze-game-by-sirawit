# เกมเขาวงกต (Maze Lab) · รุ่น 1.0.0

ห้องทดลองดูวิธีสร้างเขาวงกต 11 วิธีทำงานทีละขั้น กับเกมเดินออกจากเขาวงกตที่ให้คะแนนจากการตัดสินใจ · เกมที่เล่นจบบันทึกลงฐาน เปิดดูย้อนได้ และพิมพ์เป็นใบงาน A4 ได้

## มีอะไรบ้าง

| หน้า | ทำอะไร |
|---|---|
| ห้องทดลอง `/` | เลือกวิธีสร้าง 11 วิธี (ชี้หัวข้อกลุ่มขึ้นคำอธิบายพร้อมภาพตัวอย่าง) ปรับนิสัยของแต่ละวิธี ดูแอนิเมชันตอนสร้าง ดูเฉลย ปรับหลังสร้าง (เก็บกวาดทางตันสั้น ทางวน สุ่มหลายรอบ ย้ายทางออก) และกราฟเทียบทุกวิธี กดแถบกราฟเพื่อเลือกวิธีนั้นได้ |
| เล่นเกม `/play` | 4 ระดับ เลือกวิธีสร้าง ทางวน 5 ระดับ โหมดไฟฉาย · เดินด้วยปุ่มลูกศรบนจอ คีย์บอร์ด หรือลากนิ้ว · ปักธง (F) แล้ววาร์ปกลับ (R) · พักเกม (Backspace) · กดแท็บอื่นระหว่างเล่นถามก่อนออก · คะแนนเต็ม 100 พร้อมที่มาของก้าวเกิน · ชนะแล้วบันทึกลงฐานเอง |
| ประวัติ `/history` | เกมที่เล่นจบทั้งหมด ดูเป็นตารางหรือเป็นภาพเขาวงกตที่เล่นจบเรียงกัน · ลบวงกตได้ (ถามสองชั้น ลบแบบกู้ได้ที่ฐาน) |
| ตัวดูย้อน `/history/[id]` | ตัวละครเดินซ้ำ เร่งได้ 8 เท่า ลากไปช่วงไหนก็ได้ จุดแดงตรงที่เลี้ยวผิด ธงตรงจุดที่ปัก · เล่นด่านเดิมอีกรอบได้ |
| ใบงาน `/print` | A4 สองหน้า เขาวงกตกับเฉลย |

## เทคโนโลยี

Next.js 16 · React 19 · TypeScript · ขึ้น Cloudflare ด้วย OpenNext · ฐาน Supabase (โปรเจกต์ tb-calculator ตาราง `mz_games`) · ชุดทดสอบ `node --test` · ฟอนต์ Sarabun กับ Roboto Mono · ธีมสว่างและมืด กับภาษาไทยและอังกฤษ มีปุ่มสลับบนแถบบน · หน้าจอมือถือแยกไฟล์ (`app/mobile.css`) เพิ่มลงหน้าจอโฮมเปิดเป็นแอปได้

## เริ่มใช้ในเครื่อง

1. `npm install`
2. คัดลอก `.env.example` เป็น `.env.local` แล้วกรอก
   - `SUPABASE_SERVICE_ROLE_KEY` กุญแจฝั่งเซิร์ฟเวอร์ของฐาน tb-calculator
   - `MAZE_PASSWORD` รหัสผ่านเข้าเว็บ
   - `MAZE_AUTH_SECRET` ข้อความสุ่มยาวอย่างน้อย 32 ตัว
3. `npm run dev` แล้วเปิด `http://127.0.0.1:3600`

ไม่ใส่กุญแจฐาน เกมยังเล่นได้ แต่บันทึกไม่ได้ (หน้าจอบอกตรง ๆ)

อยากดูหน้าประวัติกับเกมค่ายาวสุด รัน `node scripts/seed-sample-game.ts` (ใส่เกมตัวอย่างหนึ่งเกม รันซ้ำได้แถวเดิม)

## ขึ้นเว็บจริง

เจ้าของโปรเจกต์ทำเอง · ตั้งตัวแปรลับ 4 ตัวบน Cloudflare (`SUPABASE_URL` · `SUPABASE_SERVICE_ROLE_KEY` · `MAZE_PASSWORD` · `MAZE_AUTH_SECRET`) · ลืมตั้งรหัส เว็บตอบ 503 ทั้งเว็บ ไม่เปิดโล่ง

⚠️ ผูก repo ให้ Cloudflare สร้างเอง อย่าสร้างในเครื่องที่มี `.env.local` แล้วส่งขึ้น เพราะตัวสร้างฝังค่าในไฟล์นั้นลงไปด้วย (รายงานตรวจข้อ 14)
