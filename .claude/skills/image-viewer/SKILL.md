## 4 อย่างที่ต้องปรับเวลายกไปเว็บอื่น

### 1. ไอคอน — Font Awesome หรือ lucide

ต้นฉบับใช้ **Font Awesome** (`<i className="fa-solid fa-*">`) ประมาณ 20 จุด
เว็บที่ใช้ **lucide-react** ต้องแปลงทีละอัน ถ้าไม่แปลง **ปุ่มจะว่างเปล่าทั้งแถบ** (กดได้แต่ไม่มีรูป)

| Font Awesome | lucide |
|---|---|
| `fa-chevron-left` / `fa-chevron-right` | `ChevronLeft` / `ChevronRight` |
| `fa-chevron-down` | `ChevronDown` |
| `fa-circle-info` | `Info` |
| `fa-ellipsis-vertical` | `MoreVertical` |
| `fa-question` | `HelpCircle` |
| `fa-xmark` | `X` |
| `fa-keyboard` | `Keyboard` |
| `fa-rotate-left` / `fa-rotate-right` | `RotateCcw` / `RotateCw` |
| `fa-expand` | `Maximize` |
| `fa-magnifying-glass-plus` / `-minus` | `ZoomIn` / `ZoomOut` |
| `fa-wand-magic-sparkles` | `Sparkles` |
| `fa-table-cells` | `Grid3x3` |
| `fa-rectangle-list` | `List` |

### 2. สี — เขียนตรง ๆ ในโค้ดหลายสิบจุด

ต้นฉบับเป็นเทลเขียว รวมไว้ที่เดียวไม่ได้เพราะเป็น inline style
**ตัวที่ปรับแล้วรวมสีไว้ที่ค่าคงที่ `C` ด้านบนไฟล์** ยกไปใช้แล้วแก้ 4 ค่านี้พอ

```ts
const C = {
  main: '#F97E60',   // ปุ่มที่กำลังเปิดอยู่ · ปุ่มหลัก
  soft: '#FFD3C4',   // ตัวหนังสือเน้นบนพื้นดำ
  bar:  '#FF9A86',   // แถบโหลด · กรอบมินิแมป · สไลเดอร์
  deep: '#C24E32',   // หัวแผงข้อมูล
};
```

### 3. 🚨 กับดักวัดขนาดไฟล์ — อันตรายที่สุด

ต้นฉบับ ถ้าไม่ส่ง `info.sizeBytes` มา จะไปวัดเองด้วยการ**เติม `?_meta=1` ต่อท้าย URL**

```js
const metaUrl = src + (src.includes('?') ? '&' : '?') + '_meta=1';
```

🔴 **ลิงก์ที่มีลายเซ็นกำกับ (signed URL) จะพังทันที** เติมอะไรต่อท้ายแล้วลายเซ็นเสีย รูปไม่ขึ้น
ตัวที่ปรับแล้วปิดไว้เป็นค่าเริ่มต้น ต้องสั่ง `allowMetaProbe` เองถึงจะทำงาน

**วิธีที่ถูก** — ส่งขนาดไฟล์เข้าไปเลยตั้งแต่แรก `info={{ sizeBytes: 395337 }}`

### 4. การย่อขยายหน้าต่าง

ต้นฉบับอ่าน `window.innerWidth/innerHeight` ครั้งเดียวตอนวาด **ไม่ฟัง resize**
ย่อจอระหว่างเปิดรูป ขอบเขตลากจะเพี้ยนจนกว่าจะวาดใหม่ด้วยเหตุอื่น
ตัวที่ปรับแล้วเพิ่ม listener ให้แล้ว — ยกไปใช้ควรเอาส่วนนี้ไปด้วย

## วิธีเรียกใช้

```tsx
const [zoom, setZoom] = useState<DOMRect | null>(null);
const imgRef = useRef<HTMLImageElement>(null);

<button onClick={() => setZoom(imgRef.current?.getBoundingClientRect() ?? null)}>
  <img ref={imgRef} src="/รูป.jpg" alt="..." />
</button>

{zoom !== null && (
  <ImageViewer
    src="/รูป.jpg"
    originRect={zoom}                        {/* ให้ภาพขยายออกมาจากตำแหน่งที่กด */}
    info={{ name: '...', format: 'JPEG', sizeBytes: 395337 }}
    onClose={() => setZoom(null)}
  />
)}
```

**ส่ง `originRect` เสมอ** ไม่งั้นภาพจะโผล่กลางจอเฉย ๆ ไม่รู้ว่ามาจากรูปไหน

### พารามิเตอร์ทั้งหมด

| ชื่อ | จำเป็น | ทำอะไร |
|---|:---:|---|
| `src` | ✅ | ที่อยู่รูปเต็ม |
| `thumb` | | รูปย่อ ใช้เป็นภาพเบลอระหว่างรอ + ภาพในมินิแมป |
| `originRect` | | ตำแหน่งรูปย่อที่กด → ภาพขยายออกมาจากตรงนั้น |
| `info` | | ข้อมูลในแผงขวา ทุกช่องใส่หรือไม่ใส่ก็ได้ |
| `onExpire` | | ลิงก์หมดอายุ → ขอใหม่ (เรียกครั้งเดียวต่อรูป) |
| `onClose` | ✅ | ปิด (ตัวดูรูปหน่วง 320ms ให้จังหวะปิดจบก่อน) |
| `hasPrev` `hasNext` `onPrev` `onNext` | | ลูกศรเลื่อนรูป |
| `menuActions` | | เมนู ⋮ มุมขวาบน — ไม่ส่ง = ไม่มีปุ่มนี้เลย |
| `infoAction` | | ปุ่มท้ายแผงขวา |
| `allowMetaProbe` | | ยอมให้วัดขนาดไฟล์เอง (ดูข้อ 3) |

## 🚨 สิ่งที่ห้ามแก้ (แก้แล้วพังแน่)

### ขอบเขตลากต้องอ่านจาก `offsetWidth` ไม่ใช่ `naturalWidth`

```js
const el = imgRef.current;
if (el && el.offsetWidth && el.offsetHeight) return { w: el.offsetWidth, h: el.offsetHeight };
```

รูป SVG มี `naturalWidth` ไม่ตรงกับขนาดที่วาดจริง ใช้แล้วลากรูปหลุดจอ

### สูตรซูมยึดจุด ห้ามเปลี่ยน

```js
if (ns <= 1.0001) { nx = 0; ny = 0; }                        // ย่อจนพอดี → กึ่งกลางเป๊ะ
else { nx = tx * k + mx * (1 - k); ny = ty * k + my * (1 - k); }  // k=1 → ไม่ขยับ = ไม่ลอย
```

บรรทัดแรกคือตัวกันรูปลอยหนีตอนย่อสุด บรรทัดสองกันรูปกระตุกตอนซูมสุดสเกล

### คีย์ลัดต้องผูกใหม่ทุกครั้งที่ซูมเปลี่ยน

`useEffect(..., [scale, hasPrev, hasNext])` — ถ้าผูกครั้งเดียว ปุ่ม `+/−` จะคิดจากค่าซูมเก่า

### พื้นหลังต้องดำล้วน ห้ามใส่เอฟเฟกต์เบลอ

กฎจาก TB Dashboard — ตัวดูรูปต้องเห็นรูปชัดที่สุด ป๊อปอัปที่เด้งทับต้องสลับเป็นพื้นดำด้วย

## ตัวอ่าน PDF — ยังไม่ได้ยก

TB Dashboard มีตัวอ่าน PDF แยกอีกตัว (`app/legacy/parts/knowledge/pdf-viewer.jsx`)
ประกอบจาก `pdfjs-dist` เอง มีค้นหาในเอกสาร แถบหน้าย่อ คุณสมบัติเอกสาร พิมพ์ นำเสนอเต็มจอ

**พี่กันสั่ง 29 ส.ค. 2569 ว่าเก็บไว้ก่อน ทำครั้งหน้า** ถ้าจะยกต้องรู้ 4 ข้อนี้
1. ต้องมีสคริปต์คัดลอก worker ตอนติดตั้ง (`scripts/copy-pdf-worker.mjs` → `public/`) ลืมรัน = จอเปล่า
2. เวอร์ชัน `pdfjs-dist` ต้องตรงเป๊ะกับ worker ไม่งั้นขึ้น error version mismatch
3. ต้องแก้ CSP — `worker-src 'self' blob:` และ `script-src` ต้องมี `wasm-unsafe-eval`
4. ใช้ `<iframe>` ดู PDF ไม่ได้ (CSP บล็อก) ต้องวาดลง canvas อย่างเดียว
